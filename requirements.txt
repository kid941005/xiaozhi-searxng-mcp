#
# 三种安装方式任选：
#
#   1) 本地源码装：
#        pip install -e .
#        （或 pip install "git+https://github.com/dairoot/mcp-calculator"）
#
#   2) 仅用 HTTP 方式把 MCP 暴露出端口，不经 bridge —— 无需本依赖。
#
#   3) 用 Docker：构建时加参数即可，无需改本文件：
#        docker build --build-arg MCP_BRIDGE_SDK=1 -t xiaozhi-searxng-mcp:bridge .
#
# 之所以默认不列在这里：SDK 体积较大且依赖 git，纯搜索场景（MODE=mcp）
